# آرشیو مطبوعات ایران — Iran Press Archive

آرشیو متن‌باز شماره‌های اسکن‌شده روزنامه‌های تاریخی ایران. فایل‌های PDF در همین ریپو نگهداری می‌شوند و فهرست پایین صفحه به‌صورت خودکار از محتوای آرشیو ساخته می‌شود.

## منابع فعلی

| روزنامه | شناسه | نوع منبع |
|---|---|---|
| توس | `tous` | پوشه گوگل‌درایو |
| جامعه | `jameeh` | پوشه گوگل‌درایو |
| عصر آزادگان | `asr-azadegan` | پوشه گوگل‌درایو |
| نشاط | `neshat` | صفحه ایندکس سایت جلایی‌پور |

## ساختار ریپو

```
archive/<id>/          فایل‌های PDF هر نشریه (یک زیرپوشه به ازای هر منبع)
data/manifest.json     منیفست مرکزی: نام، تاریخ، اندازه و sha256 هر فایل
fetch.py               واکشگر: دانلود + ثبت منیفست + بازسازی فهرست
make_index.py          بازسازی مستقل فهرست از روی محتوای archive/
urls.yml               تعریف منابع و ساختار لینک هرکدام
requirements.txt       وابستگی‌ها (PyYAML و gdown)
```

## راه‌اندازی

```bash
pip install -r requirements.txt
python fetch.py --dry-run      # گزارش بدون دانلود
python fetch.py                # دانلود + ثبت منیفست + بازسازی فهرست README
python fetch.py --source tous  # فقط یک منبع
python fetch.py --commit       # بعد از دانلود، کامیت و پوش خودکار git
python make_index.py           # فقط بازسازی فهرست (اگر دستی فایل اضافه کرده‌اید)
```

## افزودن نشریه جدید

در `urls.yml` یک آیتم اضافه کنید و `fetch.py` را اجرا کنید — بقیه (پوشه خروجی، منیفست، فهرست README) خودکار ساخته می‌شود:

```yaml
  - name: نام نشریه
    id: latin-id
    type: google_drive_folder   # یا google_drive_file / index_page / direct_files
    url: "https://..."
```

### انواع ساختار لینک پشتیبانی‌شده

- **google_drive_folder** — پوشه عمومی درایو (سطح اشتراک: «هر کس که لینک دارد»)
- **google_drive_file** — فایل تکی درایو
- **index_page** — صفحه فهرست لینک؛ با `extensions` (پیش‌فرض `.pdf`) و `recursive` (خزش زیرپوشه‌ها)
- **direct_files** — فهرست دستی URL فایل‌ها

### تاریخ شماره‌ها

تاریخ هر شماره از نام فایل استخراج می‌شود؛ هر دو قالب جلالی (۱۳۷۹-۰۳-۱۲ یا 13790312) و میلادی تشخیص داده می‌شوند و برای مرتب‌سازی به میلادی تبدیل می‌شوند. اگر الگوی نام‌گذاری خاصی دارید، در `urls.yml` کلید `date_regex` را برای آن منبع تعریف کنید (گروه‌های سال/ماه/روز).

## نگهداری در آینده

- منبع حقیقت داده، فایل `data/manifest.json` است؛ فهرست README فقط بازتولید آن است.
- فهرست README بین نشانگرهای `AUTO-INDEX:START/END` قرار دارد؛ متن دستی خارج از نشانگرها دست نمی‌خورد و می‌توانید آزادانه ویرایشش کنید.
- حذف یا تغییر نام فایل‌ها فقط با اجرای `python make_index.py` پس از آن در فهرست و منیفست منعکس می‌شود.
