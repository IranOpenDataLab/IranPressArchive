# آرشیو مطبوعات ایران (IranPressArchive)

ابزاری ساده و کم‌حجم برای واکشی و آرشیو فایل‌های مطبوعات و اسناد تاریخی ایران از منابع اینترنتی با ساختارهای متفاوت.

## چرا بازنویسی شد؟

نسخه قبلی شامل ~۳۰ اسکریپت به‌هم‌پیوسته و سه ورکفلوی زنجیره‌ای بود که عملاً با یک کانفیگ ساختگی (لینک نمونه Adobe) کار می‌کرد و در عمل چیزی دانلود نمی‌شد. نسخه فعلی عمداً مینیمال است: **یک اسکریپت، یک فایل کانفیگ**.

## اجزا

| فایل | کارکرد |
|---|---|
| `fetch.py` | واکشگر اصلی؛ چهار نوع منبع را پشتیبانی می‌کند |
| `urls.yml` | تعریف منابع (روزنامه‌ها) و ساختار لینک هرکدام |
| `requirements.txt` | وابستگی‌ها (`PyYAML` و `gdown`) |
| `state.json` | پس از اولین اجرا ساخته می‌شود؛ جلوی دانلود تکراری را می‌گیرد |
| `archive/` | پوشه خروجی؛ برای هر منبع یک زیرپوشه با همان `id` |

## راه‌اندازی

```bash
pip install -r requirements.txt
python fetch.py                # همه منابع
python fetch.py --source tous  # فقط یک منبع
python fetch.py --dry-run      # فقط فهرست فایل‌ها، بدون دانلود
```

خروجی در `archive/<id>/` ذخیره می‌شود. اجرای مجدد فقط فایل‌های جدید را می‌گیرد.

## انواع منابع پشتیبانی‌شده

در `urls.yml` برای هر منبع یک `type` مشخص کنید:

1. **google_drive_folder** — پوشه عمومی گوگل‌درایو؛ با `gdown` کل پوشه همگام می‌شود.
2. **google_drive_file** — یک فایل تکی از درایو.
3. **index_page** — صفحه‌ای که فهرست لینک فایل‌ها را نمایش می‌دهد (ایندکس آپاچی، صفحه HTML با لینک‌های PDF و…). با `extensions` پسوندها و با `recursive` خزش در زیرپوشه‌ها قابل تنظیم است. (روزنامه نشاط از همین نوع است.)
4. **direct_files** — فهرست دستی URL مستقیم فایل‌ها.

برای افزودن منبع جدید، فقط یک آیتم به `urls.yml` اضافه کنید؛ نمونه‌ها در انتهای همان فایل کامنت شده‌اند.
